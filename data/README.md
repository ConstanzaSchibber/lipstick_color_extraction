This `data/` directory contains all images, annotations, and processed outputs for the lipstick color extraction project.

> **What's committed:** annotation files, a 173-row metadata sample, and processed CSVs that are small enough to track. Files marked `†` below are not committed — they are either too large (images), regenerated by running the notebooks, or excluded to protect scraped data.

## Directory Structure

```
data/
├── img/                             # All product images (†)
│   ├── original/                    # Raw downloaded images (~9,500 files) (†)
│   ├── original_clean/              # Cleaned originals, corrupted files removed (~9,167 files) (†)
│   ├── groundtruth/                 # Manually annotated ground truth images (222 files) (†)
│   ├── annotation_sample/           # Images sampled for annotation (208 files) (†)
│   ├── annotation_sample_closed/    # Images used in closed annotation session (40 files) (†)
│   ├── annotation_label_distribution.png
│   ├── annotation_label_distribution_combined.png
│   └── product_type_distribution.png
│
├── annotations/                     # Human annotation outputs
│   ├── labels.csv                   # Per-image labels with CIELAB ground truth values (247 images)
│   ├── active_learning_queue.csv    # Images queued for annotation via active learning
│   └── masks/                       # Segmentation masks as PNG files (247 files)
│
├── processed/                       # Pipeline outputs (generated by running notebooks)
│   ├── README.md
│   ├── products_with_images.csv     # Products matched to downloaded image files (output of 1A) (†)
│   ├── corrupted_images.csv         # Log of images that failed validation (output of 1B)
│   ├── annotation_sample.csv        # Sampling frame for annotation (output of 2A)
│   ├── annotations.csv              # Processed annotation results
│   ├── annotations_combined.csv     # Annotations merged across sessions
│   ├── annotations_label_studio.json               # Label Studio export (main session)
│   ├── annotations_label_studio_closed_addition.json  # Label Studio export (closed session)
│   ├── lipstick_colors.csv          # Extracted colors per product (brand, product, shade, CIELAB)
│   └── products_pipeline.csv        # Full pipeline output with L, a, b, hex per product (output of 4) (†)
│
└── product_metadata/                # Product-level reference data
    ├── product_lipstick_metadata_sample.csv  # 173-row sample for running notebooks
    ├── product_lipstick_metadata.csv         # Full scraped dataset — not committed (†)
    └── brand_tiers.json             # Brand tier heuristics (luxury, mid-range, drugstore, etc.)
```

`†` Not committed to the repository.

## Key Files

| File | Committed | Description |
|------|-----------|-------------|
| `product_metadata/product_lipstick_metadata_sample.csv` | Yes | Starting point — 173-product sample with metadata scraped from retailer sites, including shade descriptions, skintone/undertone tags, and pricing |
| `product_metadata/product_lipstick_metadata.csv` | No | Full scraped metadata (~9,500 products); excluded from repo to protect the dataset |
| `processed/products_pipeline.csv` | No | End product — full dataset with extracted CIELAB colors (L, a, b, hex) for every product; generated by notebook 4 |
| `annotations/labels.csv` | Yes | Ground truth labels with CIELAB values; used to evaluate color extraction accuracy |

## Note on Data Availability

The full product metadata file (`product_lipstick_metadata.csv`) and all product images are not committed to protect the scraped dataset and avoid storing large binaries in git. A 173-row metadata sample is included at `product_metadata/product_lipstick_metadata_sample.csv` so the notebooks can be run end-to-end. If you need access to the full dataset for research purposes, please open an issue.
